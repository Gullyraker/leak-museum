# Security policy

This repository is **intentionally insecure**. It exists to teach secret-hygiene
anti-patterns and to serve as a test corpus for secret scanners.

- Every credential, key, token, and password in this repository is **fake**: a
  documented example value, a throwaway key generated solely for this repo, or an
  obvious placeholder. None is or ever was valid.
- Please do **not** open "vulnerability" reports or bug-bounty submissions for
  the planted secrets — that is the entire point of the project.
- If you find a value that looks like it could be a *real* secret (i.e. a
  genuine mistake by a contributor), that is a real issue: please report it
  privately so it can be rotated and scrubbed.
